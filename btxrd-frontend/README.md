# BTXRD Frontend - Bone Tumor X-Ray Detection UI

Modern Next.js web application for bone tumor classification and segmentation from X-ray images.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure API URL (defaults to http://localhost:8000)
# Edit .env.local if backend runs on different port

# 3. Start development server
npm run dev
```

Open **http://localhost:3000** in your browser.

> The backend must be running at http://localhost:8000 for the app to work.

## Tech Stack

- Next.js 14 (App Router), TypeScript, Tailwind CSS
- Zustand (state), Framer Motion (animations), Lucide React (icons)
